# robot-arm-sim documentation

Technical documentation site for the [Robot Arm Kinematics Simulator](https://github.com/rabahdj2002/robot-arm-sim).

- **Docs site:** https://rabahdj2002.github.io/robot-arm-sim-docs/
- **Live demo:** https://rabahdj2002.github.io/robot-arm-sim/
- **Tests:** https://github.com/rabahdj2002/robot-arm-sim/tree/main/tests

Covers: Denavit–Hartenberg convention, forward kinematics, DLS + CCD inverse
kinematics with restart/validity strategy, collision engine geometry, module
architecture, API reference and the test guide.
